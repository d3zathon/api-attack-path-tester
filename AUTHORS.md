# Project Authorship

## Human author and maintainer

**Nish (d3zathon)** is the project author and maintainer of API Attack-Path Tester (APIAT).

Project repository: https://github.com/d3zathon/api-attack-path-tester

Nish is responsible for the project's direction, security-testing goals, architecture decisions, integration work, testing, debugging, review, and maintenance.

## AI assistance

OpenAI's **GPT-5.6 Luna** was used as an AI development assistant during parts of the project.

AI assistance included code review, debugging suggestions, implementation assistance, documentation drafting, test design, and troubleshooting during development.

AI assistance does not imply independent authorship of the project. Human decisions, review, testing, repository control, and final acceptance remain with the project maintainer.

## Attribution principle

This repository intentionally distinguishes **human project ownership** from **AI-assisted development**. Specific commits and the Git history remain the authoritative record of changes.

This file does not claim that every line of code was manually written by the human maintainer; it documents the development process transparently.
